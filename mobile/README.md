# Ứng dụng giảng viên

Mã Flutter hiện đặt ở thư mục gốc của repo để tái sử dụng build Android và Windows hiện có. Model và nghiệp vụ chung đã chuyển vào `packages/core/`.

Thư mục này chứa cấu hình demo App Check riêng của từng máy, sinh bởi `firebase/configure-app-check.mjs`. `firebase-debug.json` bị Git bỏ qua.

Cách chạy và cấp tài khoản nằm trong [hướng dẫn Firebase Final](../docs/FINAL_SETUP.md).
