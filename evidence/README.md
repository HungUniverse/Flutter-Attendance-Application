# Bằng chứng Firebase Final

Các kết quả tự động được tổng hợp trong [báo cáo kiểm thử](../docs/test-report.md). Tệp sinh khi chạy test nằm trong `build/final-previews/` gồm PDF mẫu, kết quả ba lượt web SDK → native Windows và phản hồi AI thật khi bật `RUN_LIVE_AI`.

Thư mục `final/` lưu kết quả ba lượt Emulator, một lỗi AI thực tế, PDF sau chỉnh sửa và trang render kiểm tra font tiếng Việt. Các tệp này dùng dữ liệu tổng hợp.

Đợt triển khai này chưa thu ảnh trình duyệt, ba lượt trên Android và web đã deploy bằng tài khoản Google thật, ARTEMIS hoặc video demo. Computer Use đã dừng do không xác định được URL trình duyệt Windows.

Khi bổ sung hồ sơ nộp bài, đặt ảnh/log thực tế theo màn và ngày chạy. Chỉ đưa dữ liệu demo được phép chia sẻ vào repo. Token đăng nhập, token App Check và tệp tài khoản dịch vụ được lưu ngoài Git.
